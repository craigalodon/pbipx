# Architecture decision records

One file per decision, numbered in order: `NNNN-short-title.md`, with
**Status**, **Date**, **Context**, **Decision**, **Consequences** and
**Alternatives considered**. A decision is changed by a new record or a dated
note on the old one, never by silently editing it.
